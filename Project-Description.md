## Project Topic Area

Local AI agent orchestration and human-supervised computer automation.

The project will develop an interactive, local-first AI harness that allows open-weight models to complete multi-step tasks using controlled access to desktop applications, web browsers, files, code, and command-line tools. The system will coordinate models and tools, maintain task context and memory, require approval for sensitive actions, and verify results. A desktop interface will allow the user to monitor activity, approve actions, take control, and review completed work.
